# 01 - Variables

A **variable** is a name that refers to a value stored in memory.

```python
name = "Asha"      # str
age = 21           # int
height = 1.62      # float
is_student = True  # bool
```

## Key points
- Use `=` to assign. No type declaration is needed.
- Use `type(x)` to inspect a type; `int()`, `float()`, `str()` to convert.
- Names: letters, digits, underscores; cannot start with a digit; case-sensitive.
- Style: `snake_case` for variables, `UPPER_CASE` for constants.
- Common errors: `NameError` (undefined name), `TypeError` (mixing str and int), `ValueError` (bad conversion).
